# 🛡️ لوحة الإدارة

صفحة ويب مستقلة **بدون أي خطوة بناء** — ملف `index.html` واحد يتصل بـ Supabase مباشرة.

## الأقسام
- **نظرة عامة**: طلبات ومبيعات اليوم، عمولة المنصة المتراكمة، وكل المعلّقات (اعتمادات/سحوبات/استرجاعات/تذاكر).
- **التجّار / المندوبون**: اعتماد وتعليق الحسابات، وعرض وثائق المندوب (هوية/رخصة) عبر روابط موقّتة آمنة.
- **طلبات السحب**: موافقة → «تم التحويل» (يخصم الرصيد ويسجّل قيد محفظة ويُشعر صاحبه) أو رفض مع سبب.
- **الاسترجاعات**: موافقة/رفض.
- **تذاكر الدعم**: عرض المحادثة والرد وتغيير الحالة.
- **الكوبونات**: إنشاء وإيقاف/تفعيل.

## التشغيل (٣ خطوات)

### 1. طبّق الـ migrations
```bash
supabase db push
```
(أهمها `20260630000005_admin_access.sql` — صلاحيات الأدمن.)

### 2. أنشئ حساب الأدمن (مرة واحدة)
من لوحة Supabase:
1. **Authentication → Users → Add user**: بريد + كلمة مرور، وفعّل **Auto Confirm**.
2. **SQL Editor** — نفّذ (استبدل البريد):
```sql
UPDATE public.users SET role = 'admin'
WHERE id = (SELECT id FROM auth.users WHERE email = 'admin@example.com');
```

### 3. افتح اللوحة
افتح `admin/index.html` في المتصفح (مباشرة، أو ارفعه على أي استضافة ثابتة).
أول مرة سيطلب **Supabase URL** و**Anon Key** (من Project Settings → API) — تُحفظ في متصفحك فقط، ثم سجّل دخولك ببريد الأدمن.

> الأمان: اللوحة تستخدم مفتاح `anon` العام فقط — كل الصلاحيات تأتي من RLS
> المشروط بدور `admin`، ولا يوجد أي مفتاح سرّي في الملف.
